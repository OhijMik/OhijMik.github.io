House of Crimson

Developing a 3D horror game using the Godot game engine, focusing on immersive gameplay and atmosphere. Created and animated all character models in Blender, enhancing the visual and interactive elements of the game. Utilized the A* algorithm for enemy pathfinding, enabling dynamic and realistic AI behavior.

LoL Matchup Predictor

Built a machine learning pipeline to predict League of Legends match outcomes based on champion draft compositions. Engineered role-based feature vectors from 2,000+ professional matches and implemented K-Nearest Neighbors with hyperparameter tuning. Achieved ~55% test accuracy, demonstrating that the draft alone has limited predictive power compared to gameplay factors.

Paint Program

Developed advanced editing tools and robust file management (new/open/save). Integrated Ollama-powered AI features, enabling users to generate drawings directly from text prompts.

GunClash
